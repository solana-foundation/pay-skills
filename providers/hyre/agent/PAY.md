HYRE Agent is an AI-interpreted DeFi data layer for Solana, paid per-call via x402 on Solana mainnet (USDC, sponsored gas via the Dexter facilitator). 26 endpoints are organised into four segments — **Trenchers** (Pump.fun launches, bonding curves, snipers, graduates), **Traders** (whale PnL, top wallets, OHLCV, intel), **LPs** (Meteora DLMM pools, recommendations, rebalance signals, strategies), and **DeFi** (TVL, yields, deBridge cross-chain quotes, yield-migrate break-even math) — plus an **/ask** meta-endpoint that routes natural-language queries to the right segment, and an **/agents** registry (claim + proxy endpoints for community-run HYRE agents).

Every paid response follows the same envelope: `{ data, insight, signal, confidence, sources, model_used, latency_ms, timestamp }`. The `signal` field uses a controlled vocabulary per segment (snipe/watch/avoid for trenchers, follow/ignore for traders, add_liquidity/rebalance/hold for LPs, high_yield/low_yield for DeFi, execute/wait/avoid for deBridge quotes, migrate/stay/wait for yield-migrate) so agents can route on a typed decision rather than parsing prose. Insights are generated by a 4-model OpenRouter cascade (Claude 3.5 Haiku → GLM 4.5 Air → DeepSeek R1 → DeepSeek V3) with 8s per-model timeout; if every model fails the endpoint returns raw data with `insight: null` and HTTP 206 instead of failing the call.

## Spend-aware usage

- **Use `/ask` for ambiguous or multi-step queries.** It is the cheapest way to answer "is this token safe?" or "where should I park 50k USDC for the next 4 weeks?" because it routes internally instead of forcing the agent to discover-then-call. Reach for the typed segment endpoints only when the question is already narrow (`/traders/wallet/{address}/pnl`, `/lp/meteora/pools/{address}`).
- **Reuse the mint or wallet address across calls.** Most token endpoints (`/trenches/curve`, `/trenches/token/{mint}`, `/trenches/token/{mint}/snipers`, `/trenches/token/{mint}/verdict`, `/traders/token/{mint}/whales`, `/traders/token/{mint}/ohlcv`) accept the same Solana mint pubkey — collect the mint once, then fan out.
- **Prefer `/trenches/token/{mint}/verdict` over chaining `curve` + `snipers` + `whales` separately** when you only need a buy/avoid decision — verdict is one paid call that fuses the three signals.
- **Cache pool data on your side.** Meteora DLMM and DeFiLlama responses change on the order of minutes, not seconds. Polling `/lp/meteora/pools` or `/defi/tvl` faster than every 30–60s wastes spend without new information.
- **For cross-chain decisions, call `/debridge/yield-migrate` instead of `/debridge/quote` + `/defi/yields` separately.** Yield-migrate already includes the break-even math (gas + bridge fees vs APR delta) and returns a `migrate/stay/wait` signal.
- **The `/agents/register` endpoint is one-time per agent, not per-call.** Once an agent is claimed, address it via `/agents/{name}/{proxied_path}` for proxied access — the registry hop is free.
