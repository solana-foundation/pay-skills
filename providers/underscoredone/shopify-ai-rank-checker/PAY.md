Checks how a Shopify store's products rank when AI shopping assistants like ChatGPT, Gemini, Perplexity, Grok, and Copilot search — using Shopify's real Global Catalog index they read from. No API key or account required — pay per call in USDC via x402 on Solana (or Base).

## Spend-aware usage

- Check your highest-intent keywords only rather than an exhaustive keyword list.
- Rankings move slowly — poll on a weekly cadence, not per session.
