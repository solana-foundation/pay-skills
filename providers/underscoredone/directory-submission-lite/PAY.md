Orders submission of a website to twenty web directories that publish a backlink to it, and returns a confirmation number that can be used to check order status later for free. No API key or account required — pay per call in USDC via x402 on Solana (or Base).

## Spend-aware usage

- Submit each site once — repeat orders duplicate listings and cost again.
- Status checks are free; use the confirmation number instead of re-ordering.
